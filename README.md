# 🎵 Musik 2.0 — Персональный стриминг, «Мой поток», импорт плейлистов и мультиаккаунты

Полноценная open-source альтернатива коммерческим сервисам (Spotify / Яндекс Музыка), с интеллектуальной рекомендательной системой **«Мой поток»** (аналог *Моей волны*), импортом плейлистов по ссылке с автоматической расстановкой лайков, дизлайками и аккаунтами с поддержкой любых устройств.

---

## ⚡ Новые возможности (v2.0)

### 🌊 1. «Мой поток» (Аналог «Моей волны» в Яндекс.Музыке)
* **Адаптивный алгоритм в реальном времени:** непрерывно вычисляет вектор музыкальных предпочтений каждого пользователя на основе его лайков, дизлайков, истории прослушиваний и пропусков.
* **Бесконечный поток музыки:** треки загружаются бесшовно и непрерывно подгружают следующие партии, когда очередь подходит к концу.
* **Режимы волны:**
  * 🌊 **Всё подряд (Баланс):** гармоничное сочетание любимых треков, похожих композиций и свежих открытий.
  * ⚡ **Энергичное:** драйвовый темп (Rock, Electronic, EDM, Hip-Hop, Dance).
  * ☕ **Спокойное:** расслабляющий чилл (Lo-Fi, Acoustic, Neo-classical, Ambient).
  * ❤️ **Только любимое:** персональная коллекция и лучшие треки любимых исполнителей.
  * 🔍 **Незнакомое:** поиск новых артистов в рамках вашего музыкального вкуса без уже знакомых треков.

### 📥 2. Импорт плейлистов по ссылке с авто-лайками
* Поддержка ссылок из любых сервисов:
  * **Яндекс Музыка** (ссылки на плейлисты и альбомы)
  * **Spotify** (плейлисты и альбомы через embed)
  * **YouTube Music & YouTube** (любые плейлисты через yt-dlp)
  * **Apple Music** (публичные плейлисты)
  * **Текстовый список** (вставка треков формата `Артист - Трек`)
* **Автоматические лайки:** каждый найденный в ссылке трек автоматически добавляется в раздел **«Любимые»** вашего аккаунта и мгновенно обучает «Мой поток»!

### 👎 3. Система дизлайков (Скрытые треки)
* Кнопка дизлайка (👎) прямо в плеере и списках треков.
* При нажатии дизлайка в «Моем потоке» трек **мгновенно пропускается** и больше **никогда не будет предложен**.
* Исполнитель и жанр получают штрафные коэффициенты, защищая вас от неподходящей музыки.
* Раздел **«Скрытые»** в меню позволяет в любой момент просмотреть заблокированные треки и при желании вернуть их в рекомендации.

### 📱 4. Аккаунты для входа с любых устройств
* Регистрация и вход по логину/паролю с безопасным хэшированием PBKDF2-SHA256.
* Токены сессий: войдите со своего компьютера, смартфона или планшета в локальной сети (`http://<IP_КОМПЬЮТЕРА>:8000`).
* Все ваши лайки, дизлайки, история и персональный поток моментально синхронизируются между всеми вашими устройствами.

## ⚡ Базовые возможности

* **Каталог iTunes API:** миллионы треков с обложками высокого разрешения 600x600.
* **Чистый звук YouTube Music 160k (Opus / AAC):** стриминг без рекламы.
* **Караоке / Синхронизированные тексты песен (LRCLIB):** подсветка строк в реальном времени с кликабельной перемоткой.
* **HTTP Range (206 Partial Content):** мгновенная перемотка трека без задержек.
* **Топ-чарты стран:** еженедельные чарты России, США, Великобритании, Германии, Франции, Японии.
* **MediaSession API:** управление с клавиш клавиатуры и экрана блокировки.

## ☁️ Бесплатный запуск сайта в облаке (онлайн доступ для всех)

Так как проект использует серверный бэкенд на Python (FastAPI, yt-dlp, SQLite, стриминг 4 медиа-потоков), обычный статический GitHub Pages не поддерживает серверные процессы.

Для запуска полноценного общедоступного сайта в 1 клик:

### Способ 1: Render.com (Бесплатно)
1. Зайдите на [render.com](https://render.com) и войдите через свой GitHub-аккаунт (**Jdkdkdiriej8383**).
2. Нажмите **New +** → **Web Service**.
3. Выберите репозиторий `Jdkdkdiriej8383/musik`.
4. Нажмите **Deploy Web Service** (Render автоматически подхватит конфигурацию `render.yaml` или `requirements.txt`).
5. Через 1-2 минуты у вас будет открытая рабочая ссылка вида `https://musik-app.onrender.com`!

### Способ 2: Railway.app / Hugging Face Spaces
* Также поддерживает автоматический деплой напрямую из репозитория GitHub через подготовленный `Dockerfile` или `requirements.txt`.

## 🚀 Запуск проекта локально

### Вариант 1: Запуск через run.bat (Windows)
Просто дважды кликните по файлу `run.bat` в папке проекта.

### Вариант 2: Через терминал
```bash
cd "D:\My projects\musik"
python main.py
```

После запуска откройте в браузере:
* **На этом ПК:** [http://localhost:8000](http://localhost:8000)
* **С телефона или планшета (в той же сети Wi-Fi):** `http://<IP-вашего-ПК>:8000` (например `http://192.168.1.50:8000`)

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Воспроизведение / Пауза |
| `F` / `А` | Поставить / снять лайк (Мне нравится) |
| `X` / `Ч` | Поставить дизлайк (Скрыть и пропустить) |
| `←` / `→` | Перемотка на 5 секунд назад / вперед |
| `↑` / `↓` | Громкость +5% / -5% |
| `L` / `Д` | Открыть/закрыть караоке с текстом песни |
| `M` / `Ь` | Включить/выключить звук (Mute) |
| `/` | Быстрый поиск трека |
| `Esc` | Закрыть модальные окна, текст или очередь |
